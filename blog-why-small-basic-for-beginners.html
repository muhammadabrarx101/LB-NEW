Why we start beginners on Small Basic before Python

The first few weeks decide whether a child thinks coding is for them. Small Basic is designed to make those weeks go well.

Quick answer

Small Basic is a free, beginner-friendly programming language from Microsoft. It has real code and real errors, but very little complexity, and children can draw shapes and animations within minutes. That early success builds the confidence they need before moving to Python.

What makes it a good first language

  • Visible results immediately. A few lines draw a shape or move a turtle on screen.
  • Small vocabulary. There are only a handful of keywords to learn.
  • Helpful editor. It suggests commands as you type, which helps with spelling and syntax.
  • Readable errors. Mistakes are explained more gently than in many languages.
  • Real programming. Variables, loops, conditions and subroutines all work the way they do in other languages.

Why not start with Python?

Python is excellent, and we teach it. But for a ten-year-old's first experience, its strict indentation and error messages can feel unforgiving. A child who gets stuck on a missing colon in week one may decide coding is not for them. Starting with Small Basic means the first lessons are about ideas, not punctuation.

What children build

In our Fun with Coding course, students:

  1. Draw their first shapes on screen in the first session
  2. Use loops to draw patterns that would be impossible by hand
  3. Use variables and input to make programs that respond
  4. Use conditions to make decisions in code
  5. Combine everything into a small game to keep

Moving on to Python

Because Small Basic uses real programming concepts, students carry everything they learned into Python. The ideas stay the same; only the syntax changes. Most students move to Learn Python after a few months.

What you need

Small Basic is free and installs in a minute on Windows computers. We send setup instructions before the first session. If your child uses a Mac, mention it in your enquiry and we will advise the best option.

Frequently asked questions

What is Small Basic?
A free, beginner-friendly programming language from Microsoft, designed to teach real coding concepts with very little complexity.

Is Small Basic a real programming language?
Yes. It has real syntax, variables, loops, conditions and errors, so the skills transfer directly to languages like Python.

Does Small Basic work on Mac?
It is designed for Windows. If your child uses a Mac, tell us in your enquiry and we will suggest the best option.

When should my child move from Small Basic to Python?
Usually after a few months, once loops, variables and conditions feel comfortable.
