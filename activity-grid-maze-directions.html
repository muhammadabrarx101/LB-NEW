Grid maze directions: a coding activity without a computer

Draw a grid, add a start, a goal and some obstacles, then write arrow commands to get there. It is how many children first meet programming.

This is the same idea behind many beginner coding games: give a character step-by-step directions. Doing it on paper first makes the logic crystal clear.

  • Ages: 6–11
  • Time: 25 minutes
  • Skill: Sequencing and debugging

What you need

  • Paper with a 6×6 grid drawn on it
  • A small token (a coin, a button or a toy)
  • A pencil

Step by step

  1. Draw the maze. Mark a start square, a goal square and a few "wall" squares the token cannot enter.
  2. Agree the commands. Use arrows: ↑ ↓ ← →, each moving one square.
  3. Write the program. Your child writes a sequence of arrows to reach the goal without touching a wall.
  4. Run it. Move the token one square per arrow, exactly as written.
  5. Debug. If it hits a wall or misses the goal, find the wrong arrow and fix it.
  6. Swap roles. Your child designs a maze for you to solve.

Add loops

Once your child is confident, introduce a loop: instead of writing → → → →, write 4 × →. Ask them to rewrite their program using as few symbols as possible.

What your child learns

Sequencing, spatial thinking, debugging and, with the extension, loops: all core programming concepts.
